# Contributing guidelines

Thank you for wanting to contribute to Serenity! Whether it's an issue or a pull request, I genuinely appreciate you taking the time to help out.

Please use the respective templates for issues and pull-requests. Ensure you are following the project's [Code of Conduct](https://xn--derfrhling-eeb.net/code-of-conduct) as well.

## Pull requests

- Ensure that your pull request is actually useful and solves a problem. Creating a PR to fix a typo is generally not helpful.
- If you're unsure about a feature you want to add, create an issue first to discuss the feature. The idea can then be tweaked if necessary before starting the PR.
- Follow the existing code style.
- Run all the tests you can on your platform of choice. Notably, since the native servers do not support Windows, you may request additional testing as part of your PR if unable to run them yourself (within reason).
